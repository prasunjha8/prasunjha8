I build robotic systems at the intersection of reinforcement learning,
computer vision, and control. My work ranges from real-time embedded
control to simulation-based autonomous navigation.

---

## Featured Projects

**[Socially Aware Robot Navigation](https://github.com/prasunjha8/social-nav-research)**
Camera-only navigation for assistive robots in crowded environments, using
VLM-based scene understanding, PPO, ORCA, and ROS 2.

**[Tortoise: ROS 2 Navigation](https://github.com/prasunjha8/tortoisewithself)**
ROS 2 Jazzy and Gazebo development for the Tortoise robot: simulation,
teleoperation, SLAM, and Nav2.

**[RL Self-Balancing Motorcycle](https://github.com/prasunjha8/catkin_ws)**
Reinforcement learning agents trained with SAC to self-balance and navigate
a two-wheeled motorcycle in ROS and Gazebo.

**[Inverted Pendulum on a 4-Wheel Cart](https://github.com/prasunjha8/Inverted-Pendulum-on-a-4-wheel-Cart-)**
Real-time self-balancing using ESP8266, MPU6050, Kalman filtering, and PID.
